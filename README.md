# ArcanaInsight

애니메이션 캐릭터와 대화하며 타로 리딩을 받는 운세 종합 콘텐츠 플랫폼

## 소개

ArcanaInsight는 일본 애니메이션 스타일의 캐릭터와 상담하듯 대화하며 타로 카드를 선택하고, AI가 해석을 제공하는 웹 애플리케이션입니다.

## 주요 기능

- **캐릭터 상담** — 4명의 개성 있는 캐릭터(아르카나 / 미코 / 선화 / 호시)와 대화하며 타로 리딩
- **78장 타로 카드** — 메이저 아르카나 22장 + 마이너 아르카나 56장 완전 수록
- **다양한 스프레드** — 1장 / 3장 / 5장 스프레드 지원
- **AI 실시간 해석** — 스트리밍 방식으로 카드 해석을 실시간 제공
- **소셜 로그인** — 카카오 / 구글 계정으로 간편 로그인
- **리딩 기록** — 과거 리딩 결과 저장 및 다시 보기
