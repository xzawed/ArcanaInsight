# i18n 규칙

## 번역 키 추가 3단계 순서 (역순 시 CI 차단)

```
1. src/i18n/translations/shared/keys.ts — SharedKeys 인터페이스에 타입 추가
2. src/i18n/translations/ko/index.ts    — SSOT 한국어 값 추가 (필수)
3. src/i18n/translations/en/index.ts    — Partial<SharedKeys> 영어 값 추가
   src/i18n/translations/ja/index.ts    — Partial<SharedKeys> 일본어 값 추가
```

ko가 SSOT — en/ja에 orphan 키(ko에 없는 키)가 있으면 `pnpm i18n:check`가 exit 1.

## namespace 패턴

```typescript
// shared/keys.ts
export interface SharedKeys {
  "section.card-skin.title": string;    // namespace.component.element
  "birth-time.hour-placeholder": string;
}

// 사용 시
const { t, locale } = useT();
t("section.card-skin.title")
```

## 하드코딩 텍스트 금지

```typescript
// ❌ 금지
<h2>나만의 카드 디자인</h2>

// ✅ 필수
<h2>{t("section.card-skin.title")}</h2>
```

## locale별 date 포맷

```typescript
// ❌ 금지 — 항상 한국어 포맷
date.toLocaleDateString("ko-KR")

// ✅ locale 파라미터 반영
date.toLocaleDateString(
  locale === "ko" ? "ko-KR" : locale === "ja" ? "ja-JP" : "en-US"
)
```

## 서버 컴포넌트 vs 클라이언트 컴포넌트

```typescript
// 서버 컴포넌트 (API 라우트 포함)
import { getRequestLocale } from "@/i18n/server-locale";
const locale = await getRequestLocale();

// 클라이언트 컴포넌트
import { useT } from "@/i18n/useT";
const { t, locale } = useT();
```
