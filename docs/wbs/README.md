| B-1 | **#521** 캐릭터 이미지 사전 생성 반응형 변형 | **R2 자격증명(`.env.r2.local`)** — 작업 환경에 없어 파이프라인 끝단 검증 불가 | 변형 생성 스크립트 → 폭 매핑 로더 → `upload:assets:r2` 계열로 업로드 |

> ② 그러나 2026-08-01 CI trace 2건에서 **더 나쁜 사실**이 관측됐다 — 4.8MB 원본 12장이 Next 이미지 최적화 큐를 포화시켜 **32px 내비 아이콘까지 대기열에 갇힌다.** App Router는 새 트리가 커밋될 때까지 이전 URL을 유지하므로, 홈으로 이동하는 클릭이 **URL조차 바뀌지 않은 채 30초 넘게** 멈춘다(실측). 사용자에게는 "탭을 눌렀는데 반응이 없다"로 보인다.
>
> 즉 "콜드 캐시 첫 방문자가 조금 느리다"가 아니라 **네비게이션 무응답**이다. CI 과제가 아니라 **프런트 성능 과제**라는 분류는 유지하되, 긴급도는 낮음 → **높음**.
>
> 자격증명 없이도 **변형 생성 스크립트와 폭 매핑 로더까지는 구현·로컬 검증이 가능**하다.

## 2. 선행 조건이 있는 것 (Sequenced)

```
E2E 안정성 확보 ──▶ workers 재평가 ──▶ CI 시간 단축
     (S-1)              (S-2)
```

| ID | 작업 | 선행 조건 | 근거 |
|---|---|---|---|
| ~~S-1a~~ | ~~`Target closed` 잔여 발생률 재측정~~ | — | **완료** — 3표본 12잡에서 잔여 flake가 **단일 테스트**(`navigation` 스크롤 후 이동)로 수렴함을 확인. 나머지 9잡은 clean |
| ~~S-1~~ | ~~E2E 잔여 비결정성 제거~~ | — | **완료(#530)** — trace로 `click()` 내부 네비게이션 대기가 예산을 태우는 것을 확인하고 evaluate 디스패치로 차단 |
| ~~S-2~~ | ~~CI `workers` 상향 재평가~~ | — | **완료** — 임계경로인 Mobile Android를 2로 상향. 2런 실측: 5.0m→2.9m·4.2m→2.7m, **flaky 0**, CPU 82~86% |
| **S-3** | 임계경로가 된 Desktop Chrome 상향 검토 | — | S-2로 임계경로가 Mobile Android → **Desktop Chrome(3.8~4.7m)** 으로 넘어갔다. 같은 방식으로 매트릭스 `workers` 값만 바꿔 재측정한다 |

> **S-1a를 먼저 둔 것이 옳았다.** 원래 WBS는 S-1을 무조건 선행으로 두었는데, 그 사이 hydration 결함이 해소된 상태였다. 재측정 없이 "안정성 확보"를 선행 조건으로 걸었다면 S-2는 열리지 않았을 것이다.
>
> ⚠️ **남은 사실 하나**: `navigation` 스크롤 테스트는 여전히 간헐적으로 예산을 소진한다. 그러나 이는 **테스트 결함이 아니라 B-1(#521)이 드러나는 지점**이다 — 홈 전이가 이미지 큐 포화로 30초 넘게 커밋되지 않는다. 테스트를 더 고치는 것은 잘못된 대응이다.

> **S-3을 진행하는 방법**: `deploy.yml` 매트릭스의 `workers:` 값만 바꾸면 된다(`E2E_WORKERS`로 주입). 잡 요약에 `nproc`·피크 메모리·CPU busy%·loadavg가 매 런 기록되므로 판단 근거는 이미 갖춰져 있다.
>
> **판단 기준은 "위험"이 아니라 "이득"이다.** E2E 벽시계는 4잡의 최댓값이 정한다. #522에서 Desktop Chrome만 올렸을 때는 테스트가 30~40% 빨라졌는데도 임계경로가 Mobile Android라 **CI 총 시간이 그대로여서 되돌렸다.** #531에서 임계경로를 올려 실제 이득을 얻었고, 이제 임계경로는 **Desktop Chrome(3.8~4.7m)** 이다.
>
> **현재 실측값**: `workers:1`에서 평균 CPU busy 42~55%(hydration 결함 해소 후), Mobile Android `workers:2`에서 82~86%. 메모리는 피크 2.9~3.2GiB로 어느 쪽이든 무관하다.
