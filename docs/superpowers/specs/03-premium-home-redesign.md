# 홈 페이지 전면 리뉴얼 — 유료 수준 디자인 스펙

## 개요

ArcanaInsight 홈 페이지를 유료 운세 플랫폼 수준으로 전면 리뉴얼한다. 캐릭터 IP 중심의 팬층 확보 전략에 맞춰 캐릭터 갤러리와 일일 운세를 핵심 섹션으로 배치하고, 서비스 소개/후기/통계/FAQ/CTA까지 총 8개 섹션으로 구성한다.

## 비즈니스 목표

- **캐릭터 팬층 확보**: 캐릭터를 전면에 내세워 IP 팬덤 형성
- **재방문 유도**: 캐릭터별 일일 운세로 매일 방문 동기 부여
- **전환율 향상**: 히어로 + 하단 CTA 이중 유도로 타로 상담 전환
- **신뢰 구축**: 후기, 통계, FAQ로 서비스 신뢰도 확보

## 레이아웃 규칙 (공통 준수)

- **데스크탑(md+)**: 캐릭터 등장 시 좌 50% + 우 50% 가로 배치
- **모바일(md-)**: 위→아래 세로 배치
- 캐릭터 이미지 테두리 CSS mask 투명도 블렌딩

## 섹션별 상세 설계

### 섹션 1: 히어로 (풀스크린)

**구조:**
- 전체 뷰포트 높이 (`h-screen`)
- 풀스크린 배경 이미지 + 파티클 오버레이 + 비네팅
- 데스크탑: 좌측 50% 캐릭터(아르카나 누끼, 등장 애니메이션) + 우측 50% 카피/CTA
- 모바일: 캐릭터 상단 → 카피/CTA 하단

**콘텐츠:**
- 메인 카피: "카드가 속삭이는 당신의 이야기"
- 서브 카피: "AI 타로 상담사와 함께하는 신비로운 운세 체험"
- CTA 1 (primary): "타로 상담 시작하기" → `/tarot`
- CTA 2 (secondary/outline): "오늘의 카드 뽑기" → 섹션 3으로 스크롤
- 하단: 스크롤 유도 화살표 (바운스 애니메이션)

**애니메이션:**
- 캐릭터: 좌측에서 슬라이드인 (`initial={{ x: -50, opacity: 0 }}`)
- 카피: 우측에서 페이드인 (0.3s 딜레이)
- CTA: 카피 이후 페이드인 (0.6s 딜레이)
- 파티클: `density="medium"`

### 섹션 2: 캐릭터 갤러리 (핵심)

**구조:**
- 섹션 타이틀: "당신의 상담사를 만나보세요"
- 서브타이틀: "각 상담사만의 특별한 리딩 스타일로 카드의 메시지를 전합니다"
- 4캐릭터 대형 카드 — 데스크탑 4열, 모바일 가로 스크롤 (스냅)

**각 캐릭터 카드 구성:**
- 누끼 이미지 (상단 60%)
- 캐릭터 이름 + 일본어명
- 특기 태그 (`speciality` 필드)
- 한줄 소개 (`description` 앞 50자)
- "상담 시작" 버튼 → `/tarot` (해당 캐릭터 자동 선택)
- 캐릭터별 테마 컬러 악센트: arcana=보라, miko=빨강, seonhwa=핑크, hoshi=파랑

**인터랙션:**
- 호버: 카드 `y: -12, scale: 1.03` + 캐릭터별 컬러 글로우
- 클릭: `whileTap={{ scale: 0.97 }}`
- 스크롤 인터섹션: 카드 순차 등장 (stagger 0.15s)

### 섹션 3: 오늘의 카드 (캐릭터별 일일 운세)

**구조:**
- 섹션 타이틀: "오늘의 카드" + 날짜 표시 (`2026년 3월 29일 토요일`)
- 4캐릭터 탭 바 (가로 정렬, 선택 캐릭터 언더라인 인디케이터)
- 선택된 캐릭터 탭 콘텐츠: 데스크탑 좌 50% 카드 + 우 50% 해석, 모바일 세로

**카드 영역 (좌):**
- 카드 뒤집기 애니메이션 (처음 방문 시 뒷면 → 클릭/탭으로 앞면 전환)
- 카드 앞면: CardFace SVG 라인아트 + 카드명
- 정/역방향 표시

**해석 영역 (우):**
- 캐릭터 이름 태그 (보라 그라디언트 필)
- 오늘의 메시지 (캐릭터 말투로 3~4문장)
- 키워드 태그 3개 (카드의 upright keywords)
- SNS 공유 버튼: 트위터(X) / 링크 복사
- 로그인 유저: "이 캐릭터를 내 상담사로 설정" 버튼

**데이터 흐름:**
- 날짜 기반 시드 (`YYYY-MM-DD` 해시)로 캐릭터별 카드 1장 결정 (클라이언트)
- 해석 텍스트: API 라우트 `/api/daily-card` — Grok AI 1회 호출, 캐릭터별 말투로 짧은 해석
- 캐싱: Supabase `daily_cards` 테이블에 날짜+캐릭터별 저장, 같은 날 재요청 시 캐시 반환
- "내 캐릭터" 설정: `profiles` 테이블에 `favorite_character_id` 컬럼 추가

### 섹션 4: 서비스 소개 플로우

**구조:**
- 섹션 타이틀: "이렇게 진행됩니다"
- 4단계 가로 타임라인 (데스크탑), 세로 타임라인 (모바일)

**각 단계:**
1. 상담사 선택 — 아이콘: 사람 + "4명의 개성 있는 AI 상담사 중 선택"
2. 주제 선택 — 아이콘: 카드 + "연애, 직장, 재정, 건강, 일반 5가지 주제"
3. 카드 리딩 — 아이콘: 별 + "직감으로 카드를 선택하면 실시간 AI 해석"
4. 결과 확인 — 아이콘: 책 + "상세 해석과 조언, 저장 및 공유 가능"

**애니메이션:**
- 스크롤 인터섹션: 단계별 순차 등장 (stagger 0.2s)
- 각 단계 사이 연결선 (보라 그라디언트 라인)

### 섹션 5: 리뷰 / 사용 후기

**구조:**
- 섹션 타이틀: "상담 후기"
- 카드 캐러셀 — 자동 슬라이드 (5초 간격) + 좌우 화살표 + 도트 인디케이터
- 5~6개 후기 카드

**각 후기 카드:**
- 프로필 아이콘 (이니셜 원형)
- 닉네임 + 별점 (★★★★★)
- 후기 텍스트 2~3줄
- 상담 캐릭터 태그 ("아르카나와 상담")
- 상담 주제 태그 ("연애/관계")

**초기 데이터:** 샘플 후기 6개 하드코딩 (추후 실제 후기 시스템으로 교체 가능)

### 섹션 6: 서비스 통계

**구조:**
- 4개 지표 가로 배치 (모바일 2×2 그리드)

**지표:**
1. 누적 리딩 — 아이콘: 🃏 — 수치: "10,000+" (카운트업 애니메이션)
2. 활성 사용자 — 아이콘: 👤 — 수치: "2,500+"
3. 만족도 — 아이콘: ⭐ — 수치: "4.8/5.0"
4. AI 상담사 — 아이콘: 🔮 — 수치: "4명"

**애니메이션:** 스크롤 인터섹션 트리거 → 0에서 목표 수치까지 1.5초 카운트업

**데이터:** 초기에는 하드코딩. 추후 Supabase에서 실제 통계 조회로 교체 가능.

### 섹션 7: FAQ

**구조:**
- 섹션 타이틀: "자주 묻는 질문"
- 아코디언 6개

**질문 목록:**
1. "AI가 정말로 타로를 해석하나요?" — Grok AI 기반 해석 설명
2. "무료로 이용할 수 있나요?" — 기본 무료, 향후 프리미엄 가능성
3. "개인정보는 안전한가요?" — Supabase 보안, 데이터 저장 범위
4. "상담 결과를 다시 볼 수 있나요?" — 로그인 후 마이페이지에서 확인
5. "어떤 타로 카드를 사용하나요?" — 메이저 22장 + 마이너 56장 총 78장
6. "캐릭터마다 해석이 다른가요?" — 캐릭터별 성격/말투 차이 설명

**인터랙션:** 클릭 → `AnimatePresence` + `height: auto` 부드러운 확장/축소

### 섹션 8: 하단 CTA

**구조:**
- 풀폭 배경 이미지 + 보라 그라디언트 오버레이
- 메인 카피: "지금 바로 첫 번째 상담을 시작해보세요"
- 서브 카피: "로그인 없이도 바로 이용 가능합니다"
- 대형 CTA 버튼: "상담 시작하기" → `/tarot`
- 4캐릭터 작은 아바타 나란히 (신뢰 지표)

## 신규 API 라우트

### `POST /api/daily-card`

**Request:**
```json
{ "characterId": "arcana", "date": "2026-03-29" }
```

**로직:**
1. `daily_cards` 테이블에서 해당 날짜+캐릭터 캐시 조회
2. 캐시 있으면 반환
3. 없으면:
   - 날짜 해시 시드로 카드 1장 결정 + 정/역방향 결정
   - Grok AI 호출: 캐릭터 말투로 오늘의 카드 짧은 해석 (max_tokens: 300)
   - 결과를 `daily_cards` 테이블에 저장
   - 반환

**Response:**
```json
{
  "cardId": "major-06",
  "isReversed": false,
  "interpretation": "오늘은 연인 카드가 나왔네요냥~ ...",
  "keywords": ["사랑", "선택", "조화"]
}
```

### Supabase 스키마 추가

```sql
CREATE TABLE daily_cards (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  date date NOT NULL,
  character_id text NOT NULL,
  card_id text NOT NULL,
  is_reversed boolean DEFAULT false,
  interpretation text NOT NULL,
  keywords text[] DEFAULT '{}',
  created_at timestamptz DEFAULT now(),
  UNIQUE(date, character_id)
);
```

`profiles` 테이블에 컬럼 추가:
```sql
ALTER TABLE profiles ADD COLUMN favorite_character_id text;
```
