# ArcanaInsight UI 활성화 디자인 회의록

**일시**: 2026-05-01  
**참여자**: Visual Design Agent, Character Animation Agent, Theme/Atmosphere Agent, UX/Micro-interactions Agent, Emotional Branding Agent  
**주제**: 단조로운 화면·테마·캐릭터에 활기를 넣어 사용자에게 인상 깊고 좋은 기억을 남기는 방법  
**형식**: Claude 멀티 에이전트 병렬 브레인스토밍 → 종합 회의록  

---

## 1. 회의 배경 및 목표

현재 ArcanaInsight는 기술적 완성도(98% 커버리지, Grok+Claude 이중화, 19개 E2E 스펙)는 높으나, 시각적으로 정적이고 단조롭다는 피드백이 있다. 사용자가 앱을 열었을 때 "운명의 문을 여는 느낌", 서비스 이용 후 "오늘 하루를 선물받은 것 같은 여운"을 주는 것이 이번 회의의 목표다.

## 2. 분야별 주요 제안

### 2-A. 비주얼 디자인 (Visual Design Agent)

#### 핵심 제안: "살아 숨쉬는 캐릭터 공간"

**캐릭터별 앰비언트 배경 시스템**
- 각 캐릭터가 등장할 때 고유한 파티클/배경 레이어가 함께 활성화된다.
- 예: 아르카나 → 보라빛 별자리 SVG 레이어 + 반짝이는 루나 파티클
- 예: 미코 → 일본식 벚꽃 파티클 + 먹빛 번짐 효과
- 예: 레이 → 깔끔한 기하학 패턴 + 냉각색 글로우

**서비스별 색상 팔레트**
| 서비스 | 주색 | 보조색 | 분위기 |
|--------|------|--------|--------|
| 타로 | Indigo #3730A3 | Gold #F59E0B | 서양 신비주의 |
| 사주 | Amber #D97706 | Jade #065F46 | 동양 전통미 |
| 신점 | Crimson #991B1B | Obangsaek 5색 | 한국 무속 |

**홀로그래픽 카드 효과**
- 타로 카드 호버 시 CSS `perspective` + `rotateX/Y` 3D 틸팅
- 카드 뒷면: `conic-gradient` 홀로그램 광택
- 선택된 카드: 황금빛 외곽선 펄스 애니메이션

**별자리 연결선 레이어**
- 홈화면 배경에 캐릭터별 별자리 SVG (arcana=처녀자리, miko=게자리 등)
- 마우스 움직임에 따라 시차(parallax) 0.1× 비율로 미세하게 이동

### 2-B. 캐릭터 애니메이션 (Character Animation Agent)

#### 핵심 제안: "캐릭터가 진짜 살아있다는 느낌"

**캐릭터별 아이들 루프 애니메이션** (Framer Motion)
```
arcana: 천천히 부유 (y: 0→-8px, duration 3s ease-in-out loop)
miko:   고개를 미세하게 숙이는 묵상 (rotate: 0→-2deg, duration 4s)
hoshi:  통통 튀는 bounce (y: 0→-12px, duration 1.5s spring)
rei:    거의 움직이지 않음 + 눈 깜빡임 (opacity 1→0.85, duration 0.15s, interval 4s)
zero:   시적인 슬로우 스웨이 (x: -4→4px, duration 5s ease-in-out loop)
lix:    장난스러운 틸트 (rotate: -3→3deg, duration 2s alternate)
```

**마우스 패럴랙스 눈 추적**
- 캐릭터 이미지 위에 투명한 눈 레이어 오버레이
- 마우스 위치에 따라 CSS `transform: translate` 미세 이동 (최대 ±6px)
- 캐릭터가 사용자를 "보는" 느낌

**입장 시그니처 애니메이션**
- 캐릭터 선택 시 서비스 진입 전 0.8초 입장 시퀀스
- 예: 아르카나 → 하단에서 부드럽게 올라오며 별 파티클 산포
- 예: 호시 → 옆에서 탕 튀어나오며 별표(★) 이펙트 2~3개 피어남

**서비스 완료 후 셀리브레이션**
- 리딩 결과 도착 시 캐릭터가 `smile` 상태로 전환 (현행)
- 추가: 0.3초 지연 후 손 흔들기 or 고개 끄덕임 1회 짧은 시퀀스

### 2-C. 테마·분위기 (Theme/Atmosphere Agent)

#### 핵심 제안: "공간이 서비스의 세계관을 말한다"

**서비스별 대기실 분위기**

*타로 — 서양 신비주의 살롱*
- 배경: 심야 인디고 (`#0F0A2E`) + 별 파티클 레이어
- 테이블 위 촛불 flickering effect (CSS `opacity` 애니메이션)
- 사운드 힌트: 진입 시 신비로운 단음 (Web Audio API, 선택적)

*사주 — 동양 서재*
- 배경: 먹빛 (`#1A1209`) + 앰버 조명 글로우
- 하단 장식: 팔괘(☯) 희미한 워터마크
- 계절에 따른 배경 요소 전환 (봄=벚꽃, 여름=연꽃, 가을=단풍, 겨울=설화)

*신점 — 한국 무당방*
- 배경: 오방색 5색 그라데이션 (파랑·빨강·노랑·흰·검) 미묘하게 순환
- 배경에 부적 문양 희미하게 반복 패턴
- 방울 소리 힌트 (선택적, 300ms 단음)

**시간대별 테마 자동 전환**
```
06:00~11:59 → 새벽/아침 (차분한 푸른빛 + 여명 그라데이션)
12:00~17:59 → 낮 (밝은 금빛 + 솔직한 조명)
18:00~21:59 → 황혼 (보라+주황 매직아워)
22:00~05:59 → 심야 (짙은 남색 + 별 파티클 최대)
```

**감정 연동 색상 오버레이**
- 리딩 결과 키워드 분석 후 UI 색온도 미세 조정
- 긍정적 리딩 → 따뜻한 골드 틴트 +5%
- 주의를 요하는 리딩 → 쿨 실버 틴트 +5%
- 구현: CSS 커스텀 프로퍼티 `--result-tint` 동적 변경

### 2-D. UX·마이크로인터랙션 (UX/Micro-interactions Agent)

#### 핵심 제안: "의식(儀式)처럼 느껴지는 흐름"

**카드 셔플 의식**
- 타로 카드 선택 전: 카드 덱이 부채꼴로 펼쳐지고 → 모였다가 → 다시 펼쳐지는 0.6초 셔플
- "카드를 선택하세요" 텍스트가 타이프라이터 효과로 등장
- 카드 호버 시 약 5° 기울기 + 부드러운 상승 (translateY -8px)

**결과 순차 공개 (Sequential Reveal)**
- 현재: 전체 텍스트 한 번에 스트리밍
- 제안: 섹션별 순차 페이드인
  1. 카드 이름/위치 먼저 (0.3s)
  2. 키워드 강조 텍스트 (0.6s)
  3. 본문 해설 스트리밍 (0.9s~)
  4. 조언/마무리 문장 (완료 후 페이드인)

**공유 버튼 타이밍 최적화**
- 현재: 결과 도착 즉시 공유 버튼 표시
- 제안: 결과 텍스트 완료 후 1.5초 딜레이 → 공유 버튼 솟아오르며 등장
- "오늘의 운세를 친구에게" 마이크로카피 추가

**햅틱 피드백 (모바일)**
- 카드 선택 시: `navigator.vibrate(15)` — 짧은 물리 반응
- 결과 도착 시: `navigator.vibrate([30, 50, 30])` — 두 번 진동 패턴
- 에러 발생 시: `navigator.vibrate([100, 30, 100])` — 경고 패턴

**로딩 중 "운세 계산 중" 상태**
- 현재: 단순 스피너
- 제안: 캐릭터별 로딩 멘트 + 아이들 애니메이션 강화
  - 아르카나: "별들의 속삭임을 듣고 있어요..." (파티클 증가)
  - 호시: "잠깐만~! 계산 중이야★" (bounce 가속)
  - 레이: "..." (정지에 가까운 최소 모션)

### 2-E. 감성 브랜딩 (Emotional Branding Agent)

#### 핵심 제안: "기억에 남는 관계"

**날짜 기반 캐릭터 로테이션 (홈화면)**
- 홈화면 추천 캐릭터를 날짜 시드(`date % 12`)로 자동 변경
- "오늘의 상담사: 아르카나" 형식으로 소개
- 방문할 때마다 다른 캐릭터가 맞이하는 신선함

**"나의 상담사" 리브랜딩**
- 마이페이지 내 자주 사용한 캐릭터 → "나의 운명 상담사 ○○"
- 캐릭터와의 누적 세션 수 표시: "○○와 함께한 리딩 23회"
- 이는 사용자가 앱을 의인화된 관계로 인식하게 한다

**감성적 언어 리프레시**
| 현재 | 제안 |
|------|------|
| "타로 리딩 시작" | "오늘의 카드를 펼쳐볼까요?" |
| "결과 보기" | "운명이 속삭입니다" |
| "다시 하기" | "새로운 인연을 찾아볼까요?" |
| "공유하기" | "친구에게도 전해주세요" |
| "로딩 중" | "별들이 모이고 있어요..." |

**공유 OG 이미지 자동 생성**
- `/result/[id]` 공유 시 캐릭터 + 오늘의 키워드 + 날짜 포함 OG 이미지
- 생성: Next.js `@vercel/og` 또는 `satori`로 서버사이드 렌더링
- 공유 시 SNS 미리보기에 캐릭터 얼굴이 등장 → 앱 홍보 효과

**감사 인사 마이크로카피**
- 세션 종료/결과 완료 시 캐릭터 말투로 마무리 인사
  - 아르카나: "오늘도 별빛이 당신과 함께하기를..."
  - 호시: "내일도 또 와줘야 해~!★"
  - 레이: "이상."

## 4. 합의된 결정사항

### 결정 1: 3단계 구현 로드맵
1. **Phase 1 (즉시)**: 언어 리프레시 + 서비스별 색상 팔레트 + 카드 틸팅
2. **Phase 2 (2~3주)**: 서비스별 배경 분위기 + 캐릭터 아이들 + 결과 순차 공개
3. **Phase 3 (1개월)**: 시간대 테마 + OG 이미지 + 입장 시그니처

### 결정 2: 성능 기준선 유지
- 모든 애니메이션: `will-change: transform` + `transform: translateZ(0)` GPU 가속
- Framer Motion `lazy` 임포트 (`import { motion } from "framer-motion/m"`)
- LCP(Largest Contentful Paint) 현행 대비 +200ms 이내 유지

### 결정 3: 모바일 우선 검증
- 레이아웃 5:5 규칙 (CLAUDE.md) 침범 금지
- 새 애니메이션은 `prefers-reduced-motion` 미디어쿼리 존중 필수
- `100dvh` 기준 유지 (iOS Safari 호환)

### 결정 4: 브랜딩 일관성
- 캐릭터 말투 표 (CLAUDE.md) 준수하여 감성 언어 작성
- 새 마이크로카피는 각 캐릭터 말투 프리셋에 반영 후 서비스 전체 통일

## 5. 향후 행동 계획

```
Week 1  : 언어 리프레시 + CSS 팔레트 변수화 + 카드 틸팅
Week 2  : 캐릭터 아이들 루프 (arcana, hoshi, rei 3종 파일럿)
Week 3  : 타로 서비스 배경 분위기 + 결과 순차 공개
Week 4  : 사주·신점 배경 + 카드 셔플 의식
Month 2 : 시간대 테마 + 캐릭터 입장 시그니처 전체 12종
Month 3 : OG 이미지 + "나의 상담사" 리브랜딩 + 장기 항목 재검토
```

## 6. 에이전트 발언 하이라이트

> **Visual**: "카드가 살아있어야 한다. 홀로그램 효과 하나로 사용자는 '이건 그냥 앱이 아니다'라고 느끼게 된다."

> **Character**: "12명의 캐릭터가 모두 똑같이 서 있으면 안 된다. 레이는 거의 안 움직이고 호시는 통통 튀어야 한다 — 그게 그들의 성격이다."

> **Theme**: "공간이 서비스를 말한다. 타로방과 사주방과 신점방은 벽지부터 달라야 한다."

> **UX**: "카드를 고르는 행위는 클릭이 아니라 의식(儀式)이어야 한다. 셔플 애니메이션 0.6초가 그 문턱이다."

> **Branding**: "사용자는 앱을 기억하는 게 아니라 '아르카나'를 기억해야 한다. 관계를 파는 거다."

## 7. 결론

5개 분야 에이전트 모두 **"단조로움을 깨는 핵심은 캐릭터의 생동감과 공간의 세계관"** 이라는 점에 동의했다. 화려한 기능보다 캐릭터가 진짜 살아있다는 느낌, 그리고 서비스별로 완전히 다른 공간에 들어온 느낌이 사용자의 기억에 가장 오래 남는다는 데 합의했다.
